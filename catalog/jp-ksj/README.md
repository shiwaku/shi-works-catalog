# 国土数値情報

[English](../en/jp-ksj/README.md)

国土交通省が整備・公開している国土数値情報です。国土に関する基礎的な地理空間データ（行政区域、学校など）で、データごとに使用許諾条件が決まっています。多くは CC BY 4.0 か、政府標準利用規約（第2.0版）に準拠する国土数値情報の[利用規約](https://nlftp.mlit.go.jp/ksj/other/agreement_01.html)です。条件は各コレクションの README を見てください。

| コレクション | 内容 |
|---|---|
