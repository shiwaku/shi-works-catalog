# 道路交通センサス（2021年）

[English](../../en/jp-mlit/road-traffic-census-2021/README.md)

令和3年度（2021年）全国道路・街路交通情勢調査（道路交通センサス）一般交通量調査の箇所別基本表です。国土交通省が公開しています。高速道路、一般国道、都道府県道、指定市の主な市道の区間ごとに、交通量（12時間・24時間、上り・下り、小型車・大型車）、旅行速度（混雑時・非混雑時）、混雑度と、車線数・幅員・歩道・中央分離帯・最高速度・沿道状況などの道路状況を持ちます。事故が起きた道路の交通量や構造を調べる、交通量あたりの事故の起きやすさを比べる、といった分析に使えます。

- ファイル: [`jp-mlit-road-traffic-census-2021.parquet`](https://catalog.shi-works.com/jp-mlit/road-traffic-census-2021/jp-mlit-road-traffic-census-2021.parquet)（GeoParquet 1.1、約56 MB）
- 件数: 99,417行（1区間1行。箇所別基本表の行と同じ）。うち353行は線がない（下の「既知の注意点」）
- 範囲: 日本全国。道路状況は2021年4月1日時点、交通量は主に2021年9〜12月の平日の観測と推定
- 延長の合計: 196,237.7 km
- 座標参照系: EPSG:4326（緯度経度）。元の線は JGD2000（EPSG:4612）で、値はそのまま

国土交通省の集計結果整理表と、区間の数（道路種別ごと）と延長が合うことを確かめています。一般国道と高速自動車国道は2区間だけ区分が違います（このデータ 29,418区間・2,364区間、集計表 29,416区間・2,366区間）。

## 使い方

DuckDB で、ダウンロードせずに読めます。2025年の交通事故（[jp-npa/traffic-accident](../../jp-npa/traffic-accident/README.md)）のうち、センサスの区間から約20 m 以内で起きたものを数える例です。

```sql
INSTALL httpfs; LOAD httpfs; INSTALL spatial; LOAD spatial;
CREATE TABLE census AS
SELECT section_id, road_type, traffic_24h, length_km, geometry
FROM read_parquet('https://catalog.shi-works.com/jp-mlit/road-traffic-census-2021/jp-mlit-road-traffic-census-2021.parquet')
WHERE geometry IS NOT NULL;
SELECT count(*) AS accidents,
       count(*) FILTER (WHERE EXISTS (
         SELECT 1 FROM census c WHERE ST_DWithin(c.geometry, t.geometry, 0.0002))) AS near_census_road
FROM read_parquet('https://catalog.shi-works.com/jp-npa/traffic-accident/jp-npa-traffic-accident.parquet') t
WHERE t.statistics_year = 2025 AND t.geometry IS NOT NULL;
```

結果は287,020件のうち163,033件（56.8%）でした。距離は度で測っているので、0.0002度は南北に約22 m、東西に約18〜20 m です。残りは主に、センサスの対象でない市町村道で起きたものと考えられます。

道路種別ごとの走行台キロ（24時間交通量 × 延長）は、次のように出せます。国土交通省の集計結果整理表（交通量整理表）の値とほぼ合います。

```sql
SELECT road_type, count(*) AS sections, round(sum(length_km), 1) AS length_km,
       round(sum(traffic_24h * length_km) / 1000) AS vehicle_km_24h_thousand
FROM census GROUP BY road_type ORDER BY road_type;
```

QGIS など GDAL の Parquet ドライバを持つソフトでは、ファイルをダウンロードしてそのまま開けます。

## 使ってよいこと・いけないこと

- 幹線道路の交通量・旅行速度・道路構造の地図、事故との重ね合わせ、交通量あたりの事故率の計算に使えます。
- **対象は幹線道路だけです。** 高速道路、一般国道、都道府県道、指定市の主な市道で、ほとんどの市町村道（生活道路）は入っていません。
- **交通量の約3分の1は推定値です。** 観測していない区間は、平成27年度の交通量と周りの区間の伸び率から推定しています（`up_traffic_observed`、`down_traffic_observed` が「非観測（推定値）」）。国土交通省の説明資料は、推定値が実態と離れていることがあるとしています。区間ごとの値を使うときは、観測か推定かを確かめてください。
- 秋の平日の交通量です。休日や季節の違いは入っていません。
- 新型コロナウイルス感染症の影響が残る時期の調査です。前回（2015年）との比較では、その影響を考えてください。

## 既知の注意点

- **353区間は線がありません。** 国土交通省の可視化ツールに線がない区間（ランプ、連結区間など）で、ジオメトリを空（null）にして行は残しています。属性での集計には入り、地図には出ません。
- **線は道路中心線とは限りません。** 可視化ツールの線をそのまま使っています。上下線を別の線で描いた区間があり、線の長さは区間延長より長くなります（線が2本以上ある区間は18,570）。延長は `length_km` を使ってください。
- **交通量・旅行速度・道路状況は、それぞれの調査単位区間の値です。** いくつかの交通調査基本区間を集約した調査単位区間ごとに調べていて、同じ調査単位区間の区間は同じ値を持ちます（`traffic_unit_section_number` など）。調査単位区間の数より行が多いので、区間の数で平均すると、短い区間に分かれた調査単位区間の値が重く数えられます。延長で重み付けしてください。
- **交通量が空の区間があります。** 推定できなかった区間など、24時間交通量が空の区間が3,413あります。
- **コードはラベルに直しています。** 道路種別、管理区分、沿道状況などのコードは、説明資料の区分名（日本語）にしました。「あり・なし」の列（`has_railway_crossing` など）は真偽値です。元のコードは列の説明に書いています。
- **元データで先頭の0が落ちていたコードを補いました。** `admin_code`（市区町村コード）、調査単位区間番号、都道府県指定市コードは、5桁の文字列にしています。
- **市区町村コードは2021年4月1日時点です。** 浜松市の区など、その後の再編で変わったコードは、行政区域（[jp-ksj/admin-boundaries](../../jp-ksj/admin-boundaries/README.md)）とコードで結合できません。
- **代表沿道状況の人口集中地区は平成27年国勢調査のものです。** [人口集中地区（2020年）](../../jp-stat/densely-inhabited-districts-2020/README.md)とは範囲が違います。
- **観測年月日には、個別調査の日付が入っている区間があります。** 平成27年度以降の個別調査の観測値を使った区間（`up_individual_survey_used` が true）は、2016〜2022年の日付です。交通量は令和3年の値に換算されています。

## 加工の記録

国土交通省が公開している次の2つから、このリポジトリの [`scripts/jp-mlit-road-traffic-census-2021/build.py`](https://github.com/shiwaku/shi-works-catalog/blob/main/scripts/jp-mlit-road-traffic-census-2021/build.py) で作りました。

- [箇所別基本表](https://www.mlit.go.jp/road/census/r3/index.html)（都道府県別の CSV、47個）
- [可視化ツール（WEBマップ）](https://www.mlit.go.jp/road/ir/ir-data/census_visualizationR3/index.html)の線の GeoJSON タイル（ズーム12、道路種別ごと、18,004枚）

1. 47個の CSV をつなぐ（99,417行）。末尾の6列は先頭の6列の繰り返しなので使わない
2. 列名を英語の snake_case にし、コードをラベルか真偽値に、数値を整数・実数にする。先頭の0が落ちたコードを補う
3. タイルの境目で切れた線を、区間番号ごとにつないでマルチラインにする（127,363本 → 99,064区間）
4. 箇所別基本表に線を区間番号で結び付ける。線がない区間はジオメトリを空にする
5. 座標系の指定を JGD2000（EPSG:4612）から EPSG:4326 に変える（座標の値は変えない）
6. `portolan add` で、Hilbert 曲線の順に並べ、bbox 列を足し、GeoParquet 1.1 で書き直す

コードとラベルの対応は、国土交通省「[箇所別基本表及び時間帯別交通量表に関する説明資料](https://www.mlit.go.jp/road/census/r3/data/pdf/kasyorep.pdf)」第5章によります。
