# 国土交通省

[English](../en/jp-mlit/README.md)

国土交通省の道路・交通などのデータです。国土数値情報と PLATEAU は、データが多く利用条件もデータごとに決まっているので、別の管理者（[jp-ksj](../jp-ksj/README.md)、jp-plateau）に置いています。利用条件は、公共データ利用規約（第1.0版）に準拠する[国土交通省ウェブサイトの利用ルール](https://www.mlit.go.jp/link.html)です（CC BY 4.0 と互換性があります）。詳しくは各コレクションの README を見てください。
