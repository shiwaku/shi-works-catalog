# 交通事故統計（本票）

[English](../../en/jp-npa/traffic-accident/README.md)

警察庁が公開している「交通事故統計情報のオープンデータ」のうち、本票（人身事故1件ごとの記録）の2019〜2025年分です。1行が1件の事故で、発生地点の点と、日時・道路・天候・当事者（A・B）などの項目を持ちます。値はコードではなく日本語のラベルです。

- ファイル: [`jp-npa-traffic-accident.parquet`](https://catalog.shi-works.com/jp-npa/traffic-accident/jp-npa-traffic-accident.parquet)（GeoParquet 1.1、約132 MB）
- 件数: 2,182,298件
- 範囲: 日本全国。統計に計上された年が2019〜2025年の事故（事故が起きた日は2015年12月12日〜2025年12月31日）
- 座標参照系: EPSG:4326（緯度経度）
- 人身事故だけです。物損事故は入っていません。

## 件数

統計に計上された年（`statistics_year`）ごとの件数です。警察庁の公表値と一致します。

## 使い方

DuckDB で、ダウンロードせずに必要な列だけを読めます。

```sql
INSTALL httpfs; LOAD httpfs;
SELECT statistics_year, count(*) AS accidents, sum(fatalities) AS fatalities
FROM read_parquet('https://catalog.shi-works.com/jp-npa/traffic-accident/jp-npa-traffic-accident.parquet')
GROUP BY statistics_year
ORDER BY statistics_year;
```

QGIS など GDAL の Parquet ドライバを持つソフトでは、ファイルをダウンロードしてそのまま開けます。

## 使ってよいこと・いけないこと

向いていること:

- 事故が多い場所・時間帯・道路の形を調べる（地図、ヒートマップ）
- 年ごとの推移、都道府県ごとの比較、当事者の種別（歩行者、自転車など）ごとの集計
- 生活道路（車道幅員5.5m未満）での事故の分析

向いていないこと:

- 物損事故を含む事故の全体を数えること（人身事故だけのため）
- 10代・20代など、細かい年齢で数えること（年齢は年齢層で、最も若い区分が0〜24歳）
- 個人や個別の事故を特定すること

## 既知の注意点

- **年の数え方が2通りあります。** `statistics_year`（統計に計上された年）で数えると警察庁の公表値と一致します。`occurred_year`（事故が起きた年）で数えると、年末の事故の一部が翌年の統計に入るため、最新の年が約3%少なく出ます。経年の推移には `statistics_year` を使ってください。
- **当事者Aは過失が最も重い側、Bはその相手です。** 被害者・加害者の区分ではありません。
- **死亡事故は少ないです。** 7年間で18,761件で、細かく絞ると年に数件になります。
- **2020年は新型コロナウイルスの影響で、件数が前年より約19%減っています。** 件数だけで傾向を読まず、構成比なども合わせて見てください。
- 2019〜2021年は、2022年に加わった項目（日の出・日の入りの時刻、オートマチック車、サポカー、認知機能検査経過日数、運転練習の方法）が空です。
- 座標がおかしい171件（`(0, 0)` が150件、日本の外が21件）は、行を残してジオメトリを空にしています。件数は公表値と合いますが、地図には出ません。

## 加工の記録

元データ（Shift_JIS の CSV、コード値）から、次のように作りました。

1. [npa-traffic-accident-converter](https://github.com/shiwaku/npa-traffic-accident-converter)（コミット `583e891`）: コードを警察庁のコード表でラベルにし、度分秒の緯度経度を10進数にして、7年分をつなげる
2. [npa-traffic-accident-analytics](https://github.com/shiwaku/npa-traffic-accident-analytics)（コミット `c3e52f5`）の `pipeline/build_parquet.py`: 統計に計上された年の列を足す
3. このリポジトリの [`scripts/jp-npa-traffic-accident/build.py`](https://github.com/shiwaku/shi-works-catalog/blob/main/scripts/jp-npa-traffic-accident/build.py):
   - 列名を英語の snake_case にし、件数・人数・年月日・時刻を整数にする
   - 事故が起きた日時の列（`occurred_at`）を足す
   - コードのまま残っていたオートマチック車・サポカー・運転練習の方法をラベルにする
   - 度分秒と10進数の緯度経度の列を除き、ジオメトリにする。日本の外の座標はジオメトリを空にする
4. `portolan add`（portolan-cli 0.8.0）: 行を空間の順（Hilbert 曲線）に並べ、bbox 列を足し、GeoParquet 1.1 で書く
